# Sprint Planning — AgendaPet Web

## Meta da Sprint

Entregar um painel de agendamentos para o pet shop
Patinhas & Cia, permitindo cadastrar atendimentos,
evitar conflitos de horários, consultar CEP e feriados,
acompanhar os serviços e calcular o fechamento do dia.

## Período

16/10/2026 a 03/11/2026.

## Ordem de desenvolvimento

1. Criar a estrutura HTML e os estilos CSS.
2. Organizar o catálogo de serviços.
3. Desenvolver as classes e as regras de negócio.
4. Implementar o formulário de agendamento.
5. Criar a agenda do dia e seus filtros.
6. Integrar as APIs de CEP e feriados.
7. Implementar o armazenamento local.
8. Adicionar relógio e lembretes.
9. Criar os scripts Node.js.
10. Executar testes e preparar a documentação.

## Riscos identificados

- Instabilidade das APIs externas.
- Erros de preenchimento dos formulários.
- Conflitos entre horários.
- Problemas no armazenamento local.
- Tempo limitado para testes e documentação.

## Soluções previstas

- Tratar falhas das APIs com mensagens amigáveis.
- Permitir preenchimento manual do endereço.
- Validar os dados antes de salvar.
- Utilizar try/catch no armazenamento.
- Testar os requisitos principais antes da entrega.
